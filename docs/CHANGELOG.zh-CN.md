# 改动记录

[English](CHANGELOG.md)

本页记录用户可见行为、接口和兼容性变化；构建与测试命令见[构建指南](BUILDING.zh-CN.md)。

## 0.3.8（未发布）

### 2026-11-27 — 外部发行包默认携带 Java 21

- `externalDistZip` 现在默认运行 JDK 21 `jlink` 并携带 `runtime/`，玩家无需另行安装 Java。
- 使用 `-PbundleRuntime=false` 可显式生成无运行时精简包；默认运行时任务在非 JDK 21 构建环境下明确失败。

### 2026-11-27 — 原版 MOD 内嵌 ACMOD 成为 API 默认能力

- API 默认扫描本地与 Steam 下载的原版 MOD：根目录 `AcbricMod/` 中唯一 `*.jar` 会显示“携带AcbricMOD”和“启用携带ACMOD”。
- 安装复用 Fabric 元数据校验与原子发布，复制到 Acbric Java MOD 文件夹并移除停用项；同名冲突、多个 JAR、损坏元数据和受保护 ID 均拒绝。
- 独立 `acbric_embedded_mods` 不再需要，也不应与新版 API 同时安装。
- 验证：全量 16 套件 1223 项通过，其中 `mods` 83 项；真实 Knot 探针同时识别本地与 Steam 载体，并直接调用变换后的 `ModsScreen$5.name` 验证行后缀注入。

### 2026-11-23 — Java MOD 多语言描述

- `fabric.mod.json` 可通过 `custom.acbric.description` 提供原版游戏支持的语言：`en`、`chi`、`de`、`fr`、`jpn`、`kor`、`ru`。
- 原版 MOD 列表和 Acbric 详情页按游戏 Locale 选择文本；未提供当前语言时回退英文，再回退顶层 `description`。
- 模板支持 `modDescriptionEnglish` 与 `modDescriptionChinese`。`gradle.properties` 中的中文使用 Unicode 转义，避免 Java Properties 解码乱码。

### 2026-11-21 — Steam 启动与创意工坊

- 首页新增“Steam 启动（正版）”，直接启动仍为默认方式。
- Steam 模式仅适用于 Steam App `342560`；子 JVM 继承 Steam 环境，并在启用 Steamworks 前校验 App/Client/Launch 标识。
- 创意工坊订阅在首次启动或 MOD 更新后可能先同步，期间主菜单可能等待。

### 2026-11-18 — 战斗命令面板控件

- 新增 `context.commandPanelUi()`，每个 MOD 最多 4 个按钮、开关或状态标签，全局最多 32 个。
- 支持面板上方锚点与游戏视口九宫格锚点、有界偏移、横向行和纵向侧边栏。
- 只负责绘制与确认交互，不自动同步玩法、不调整原生面板尺寸，也不提供快捷键。

## 0.3.7.1 — 原生界面清晰度（2026-11-06）

- 100%/150%/200% 直接使用原版小/中/大素材；中间比例从较高档位向下采样。
- 保留原版字体档位、固定标题尺寸、纹理过滤和渲染分辨率。

## 0.3.7 — 原生界面百分比缩放（2026-11-06）

- 新增 `UiScale.setPercent(50..200)`、`percent()` 和 `useVanilla()`。
- 100% 对应原版小号；0 表示沿用原版。API 只管理进程级显示请求，不保存设置。

## 0.3.6 — 联机大厅与房主权威规则（2026-10-03）

- 准备凭据按玩家会话保留；成员进出、规则更新和原生大厅设置不再整批撤销准备。
- 代码检查超时后自动退避重试；原生 `ResumeScreen` 重建大厅后自动恢复已表达的准备意愿。
- 新战役采用房主广播的规则快照，其他玩家在本地校验后采纳；不覆盖本机配置文件。
- 大厅状态按钮打开联机大厅面板，可重新检查、进入 MOD 设置并修改下次启动的 MOD 启停。
- `UiWindow` 节点上限调整为 4096、深度 32。

## 0.3.5.1 — Java MOD 与原生 MOD 根隔离（2026-09-30）

- 修复共享模式下 `fabric.modsFolder` 被原生 MOD 根覆盖、导致 Java MOD 不加载的问题。
- Java `.jar` 始终使用框架 `mods`；原生 MOD 和 `acbric_vanilla/` 使用当前数据环境的原生 MOD 根。
- 编译基线与兼容目标更新为游戏 1.2.15.3，并继续支持 1.2.15.2。

## 0.3.5 — 共享数据环境（2026-09-30）

- 默认“一键同步”直接使用原版存档与 MOD，不复制文件。
- 可选“环境隔离”将原版数据完整镜像到实例，并在覆盖或删除前备份。
- 模式按实例记录；切回共享不会删除隔离副本，原版目录不会被框架删除。

## 0.3.4 — 引擎输入类型兼容（2026-09-30）

- 移除 `SlickEngine$MyInput` 硬编码，兼容 Slick 与 LWJGL3 引擎输入实现。
- 结束 `0.3.3-dev` 版本线。

## 0.3.3-dev.33 — Windows 玩家启动器（2026-09-27）

- 新增 `Acbric.exe`，提供游戏发现、首次配置、直接启动、诊断导出和本地更新/恢复。
- 旧 CMD 工具移至 `advanced/`；实例脚本继续兼容。

## 0.3.3-dev.30–32 — 安装与列表修复

- dev.31：首次配置、读取已保存配置和损坏配置提示更明确。
- dev.32：Windows 首次实例目录发布遇到 `AccessDeniedException` 时进行有限重试。

## 0.3.3-dev.25–29 — 外部安装器与更新

- `Acbric.exe`、启动脚本和 `mods/` 统一到同一层级。
- 旧布局数据不自动迁移。

## 0.3.3-dev.24 — 外部菜单与 Unicode 路径（2026-09-26）

- 外部入口可启动真实游戏菜单并加载原版资源、音频与中文安装路径。
- 已知原生地形 GL 异常继续挂起，未屏蔽或伪装成功。

## 0.3.3-dev.22–23 — 外部安装预检查与缓存隔离

- 新增外部安装预检查：游戏 A/B、依赖顺序、重复类、版本、代码指纹和实例锁。
- 启动设置与用户数据限制在实例；纹理读取和 raw 缓存按来源隔离。

## 0.3.3-dev.20–21 — 开发者工具与控制台

- 新增命令注册、类型参数、帮助、补全、注销以及游戏内控制台。
- 控制台提供状态、MOD、诊断筛选与异步导出；`~` / `GRAVE` 为固定入口。

## 0.3.3-dev.13–19 — 公共 UI 与设置

- dev.13：标签、按钮、开关、单行文本、布局、面板、滚动区、模态窗口与托管清理。
- dev.14：跟随游戏 Locale 的中英文选择。
- dev.15–17：修复原生绘制、文本定位、切屏命中与关闭字形。
- dev.18：显式字段设置页、草稿、校验、默认值、重读和磁盘冲突保护。

## 0.3.3-dev.12 — Java MOD 启停

- MOD 列表可启用或停用直属 Java `.jar`，下次启动生效，不热卸载、不删除归档。
- 启动器在 Loader 解析前过滤停用项，并校验保护组件、依赖、别名和冲突。
- 有归属记录的配套原版资源随 Java MOD 停用而屏蔽；旧目录须显式迁移。

## 0.3.3-dev.8–11 — 联机身份与规则

- dev.8：内部代码握手、有界重试、会话过期和不可验证状态。
- dev.9：大厅接入代码检查、状态按钮及准备/开局门禁。
- dev.10：共享玩法规则声明、生成前固化和续局校验。
- dev.11：旧存档规则预检查、显式接纳、直接版本转换和另存，不覆盖原档。

## 0.3.3-dev.7 — 代码清单

- 导出已加载 MOD、游戏身份和 `acbric` 入口状态，支持严格离线比较。
- `CODE_MATCH` 只表示启动代码身份一致，不认证玩家，也不代表状态同步。

## 0.3.3-dev.6 — 订阅范围

- 新增 `context.eventScope`，集中注销监听、记录归属诊断并让旧快照失效。
- 受管理异常仍原样传播，不自动禁用或重试。

## 0.3.3-dev.5 — MOD 配置

- 新增按 MOD 隔离的严格 JSON 配置、默认值、校验、显式迁移、重读、备份和原子保存。
- 配置不自动广播，也不在加载时静默重置损坏或未来版本文件。

## 0.3.3-dev.3–4 — 战役数据与生命周期

- dev.3：按 MOD ID 保存战役 JSON，读取返回独立快照，写入不广播；损坏声明块中止加载。
- dev.4：新增 `CREATED`、`LOADED`、`RESTORED`、`EXITED`，区分生成、加载、本机恢复和活动战役退出。

## 0.3.3-dev.2 — 启动诊断

- 在依赖解析前读取 `AGame.VERSION`，并为游戏代码归档生成有序 SHA-256 指纹。
- 每次启动写独立会话报告，区分 Loader 已加载、无入口、运行中、成功和失败。

## 0.3.3-dev.1 — API 兼容基线

- 保留 0.3.2 公共成员，新增 `RENAME_SHIP_*`，旧 `ONE_SHOT_*` 原地弃用但继续兼容。
- 修正数据加载错误传播、一次性事件、资源归属、类路径隔离和 MOD 安装元数据校验。
- Java 输出统一为 21，自有源码使用 UTF-8 和中文职责注释。
