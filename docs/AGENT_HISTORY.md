# 工程决策简史

[当前维护指引](../AGENTS.md) · [改动记录](CHANGELOG.zh-CN.md)

本页只保留影响当前架构的工程决策。验证数量、构建证据、提交状态和临时工作区路径不属于产品文档。

## 启动与兼容

- 启动垫片接入 Fabric Loader，同时保留原生 JSON MOD 系统；启动层不依赖游戏 API，API 层依赖游戏与 Loader。
- 游戏版本在依赖解析前从 `AGame.VERSION` 读取，代码归档按顺序计算指纹。
- 框架不得写死具体引擎输入类型；Slick 与 LWJGL3 都通过类能力或通用接口识别。
- 公开 API 保持兼容；旧 `ONE_SHOT_*` 事件原地弃用，新代码使用 `RENAME_SHIP_*`。

## 数据与资源

- 配置、战役数据、共享规则和用户资源使用不同命名空间与格式，不以“代码一致”代替状态同步。
- 配置保存使用锁、冲突检查和原子替换；损坏或未来版本文件不静默重置。
- 配套原版资源以 SHA-256 归属区分框架文件、用户修改和未归属冲突；旧目录只允许显式迁移。
- Java MOD 与原生 MOD 使用不同根，不能用一个路径覆盖另一个。

## UI 与工具

- 公共 UI 使用游戏原生字体、面板、按钮和输入链路，不引入浏览器或第二套 GUI 运行时。
- UI 只在游戏线程打开和交互；模态窗口不暂停模拟或网络 tick。
- 命令与控制台共享同一注册表，执行绑定游戏线程；`SHARED` 命令仍未开放。
- 战斗命令面板控件与通用 UI 分开维护，只负责绘制和确认交互。

## 发行与环境

- 玩家使用外部发行包引用已有游戏，默认共享原版存档与 MOD，可选择隔离副本。
- 干净发行使用 `externalDistZip`；旧 `distZip` 含本地游戏内容，仅用于旧布局开发。
- `-PbundleRuntime` 使用当前构建 JDK 生成运行时，不固定为某个 Java 版本。
- 更新与恢复保留文件归属、冲突检查、实例锁和中断恢复；哈希验证不认证发布者。

## 已明确不做

- 不自动迁移旧布局实例。
- 不热卸载 Java MOD。
- 不把代码清单一致当作身份认证、反作弊或完整状态同步。
- 不隐藏原生 GL 错误，也不将暂缓问题描述为已修复。
